# Toric-code research map: 2020-2026

Research reviewed September 2026. The numbered list contains more than fifty papers whose publication/preprint dates fall in 2020-2026. The original Kitaev toric-code work predates this window and is listed separately as foundational background rather than counted.

Each result remains attached to its dimensionality, lattice, noise model, decoder and hardware assumptions.

## Research conclusions carried into the workflow

- The 2D square toric code is the cleanest homological QEC reference: local checks, two logical qubits, distance proportional to linear size and logical failure determined by nontrivial homology.
- Periodic topology is a real architecture requirement. A planar hardware layout pays for seam interactions unless movement, long-range gates, modular links or multilayer routing supplies them.
- Decoder performance depends strongly on the noise layer. Code-capacity thresholds, phenomenological thresholds and circuit-level thresholds remain different datasets.
- Correlation-aware, biased-noise, local and hardware-accelerated decoders can materially alter the accuracy/latency tradeoff relative to vanilla MWPM.
- 3D/4D and subsystem toric variants introduce properties absent from ordinary 2D toric code, including single-shot behavior and richer transversal-gate structure. These properties remain dimension/architecture specific.
- Toric ground-state/anyon experiments establish the underlying topological physics, while repeated syndrome-extraction experiments establish QEC operation. The workflow distinguishes these evidence classes.
- A zero syndrome after recovery proves return to the codespace; logical success additionally requires trivial residual homology.
