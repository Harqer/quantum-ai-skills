# Example 9: eight-ion 171Yb+ ququart processor

A 2025 experiment demonstrated eight individually controllable four-level qudits in a 171Yb+ ion string.

Hardware/encoding:

~~~text
trap: 3D linear Paul trap
ions: 8
local dimension: 4
encoding transitions: E2 optical transition at 435 nm
effective information capacity: up to 16 binary basis bits of Hilbert-space capacity across the 8 carriers
~~~

The experiment reported individual addressing/readout and basic algorithm execution, including Bernstein-Vazirani, Grover search, H2 simulation and LiH simulation.

Use this result as evidence that multicarrier ququart processing is physically realizable. Before using it in a resource estimate, obtain the exact gate fidelities, connectivity and public access path for the target processor rather than transferring values from a different trapped-ion qudit experiment.
