## Width accounting

Do not automatically replace N qubits by ceil(N/log2(d)) qudits. That expression is only an information-capacity lower bound. In particular, d=8 means one eight-level carrier can label eight basis states; it does not mean the device exposes three independent physical qubits or their native binary gate set.

For packed virtual qubits:

~~~text
virtual_qubits_per_carrier = floor(log2(d))
~~~

For n packed virtual qubits choose d >= 2^n. Mark unused states as leakage or guard states.

The demonstrated 25-level 137Ba+ carrier can encode at most four binary virtual qubits without changing semantics because 16 <= 25 < 32.

## Star-topology single-qudit compilation on 137Ba+

The 2026 25-level experiment uses |0> in S_1/2 and states |i> in D_5/2 connected through 1762 nm electric-quadrupole transitions. The physical transition graph is a star.

Use Givens rotations on span{|0>,|i>}:

~~~text
G_0i(theta) = exp[-theta (|0><i| - |i><0|)]
~~~

To compile arbitrary U in U(d):

1. Set V=U.
2. Clear column 0 with allowed G_0i rotations.
3. For each remaining column k, swap row k into the 0 pivot with G_0k(pi/2).
4. Eliminate entries below the pivot using allowed G_0i rotations.
5. Apply G_0k(pi/2) again to restore row ordering.
6. Continue until V=I.
7. Reverse the recorded sequence and take adjoints.

The demonstrated construction uses:

~~~text
N = (d-1)(d+4)/2
~~~

Givens rotations in the generic star-topology decomposition. Treat this pulse count as a control cost.

## Native 40Ca+ two-qudit light-shift gate

Encoding:
- |0> in S_1/2,m_j=-1/2.
- |1> through |d-1> in selected D_5/2 sublevels.

Local control:
- resonant 729 nm pulses.

Entangling control:
- two approximately 401.2 nm beams.
- beat note near the axial COM mode.
- cyclic X_d permutations to symmetrize state-dependent phases.

Target:

~~~text
equal basis indices     -> phase 1
unequal basis indices   -> phase exp(i theta)
~~~

The experiment used two ions about 110 micrometres above a segmented surface Paul trap operated near 35 K with axial COM frequency near 1.1 MHz. Reported extracted gate fidelities were approximately 99.6%, 98.7%, 97.0%, and 93.7% for d=2,3,4,5 under the paper's repeated-gate/SPAM-corrected procedure.

## Multitone 137Ba+ algorithm path

The 2026 Grover experiment selected d=5 or d=8 states from the metastable 5D_5/2 manifold of 137Ba+.

Control:
- up to d-1 RF tones generated by phase-coherent DDS channels.
- tones combined onto trap electrodes.
- state selection favors strong transitions, lower magnetic sensitivity, and spectral separation from leakage transitions.
- perform spectroscopy and individual Rabi calibration first.
- tune simultaneous-tone amplitudes with randomized-benchmarking sequences and numerical optimization.

The demonstrated d=5 Grover implementation achieved 96.8(3)% target-state success for one iteration; the d=8 implementation achieved 69(6)% average success with 97.1(3)% squared statistical overlap. The demonstrated single-qudit algorithm used no entangling gate.

## Native d=8 transmon spin-control path

Use the first eight transmon energy eigenstates as one physical qudit:

~~~text
H_8 = span{|0>,|1>,...,|7>}
~~~

If the source algorithm is binary, an encoding such as

~~~text
|b2 b1 b0> -> |j>,  j = 4*b2 + 2*b1 + b0
~~~

is a basis labelling only. It does not create three independently addressable physical qubits inside the carrier.

### Demonstrated local control model

For the 2025 spin-7/2 transmon experiment:

- all seven adjacent transitions are addressed with simultaneous multifrequency drives;
- calibrated relative tone amplitudes implement an effective spin displacement `D(theta)`;
- arbitrary state-dependent phase layers are implemented virtually as SNAP-style phase updates `S(phi)`;
- arbitrary single-qudit unitaries are synthesized as alternating virtual phase and physical displacement layers:

~~~text
U = S(phi_N) D(theta_N) ... S(phi_1) D(theta_1) S(phi_0)
~~~

The experiment found O(d) displacement layers numerically sufficient for arbitrary SU(d) synthesis and focused calibration on high-fidelity pi/2 displacements. Treat virtual SNAP layers as phase-frame updates rather than physical pulses when the control stack supports that interpretation.

Measured evidence to preserve in the cost model:
- eight-state single-shot multitone dispersive readout;
- spin-displacement fidelity spanning about 0.997 to 0.989 through d=8;
- d=8 quantum Fourier transform average gate fidelity 0.91(6).

### Compiler rule

For a binary reversible operation whose entire support is inside one d=8 carrier:

1. Form its exact 8x8 permutation/unitary on the encoded basis.
2. Preserve basis-state phases, not only the classical truth table.
3. Synthesize that unitary directly in the d-level gate set.
4. Prefer spin-displacement + virtual-SNAP synthesis over re-expanding it into binary X/CNOT/Toffoli gates.
5. Verify the resulting 8x8 matrix against the intended encoded operation.

This permits several binary gates acting within the same encoded triple to fuse into one qudit unitary.

For any operation spanning two or more physical transmons:
- classify it as inter-carrier;
- do not infer a two-qudit gate from single-qudit SU(8) controllability;
- require a demonstrated interaction Hamiltonian and an accessible backend control primitive;
- include routing, spectral crowding, leakage, pulse duration, and measured inter-carrier fidelity in the cost.

Until that boundary is satisfied, `ceil(N/3)` transmons for d=8 is a capacity/width target, not a proof of an executable N-bit circuit.

## Transmon qutrit gate-reduction path

Keep the logical representation binary:

~~~text
|0>, |1> = computational
|2>      = temporary workspace
~~~

Require calibrated access to both 0-1 and 1-2 transitions plus the two-transmon interaction used by the decomposition.

Compile the multiqubit gate through temporary population of |2>, then uncompute into the qubit subspace.

Acceptance tests:

~~~text
population_outside_01 <= leakage_budget
logical truth table correct
relative phases correct
process fidelity measured
gate count or depth lower than binary baseline on the same topology
~~~

The fixed-frequency-transmon ternary Toffoli experiment used four two-transmon operations versus eight order-preserving CNOTs for a binary linear-topology decomposition and measured 78.00 +/- 1.93% average process fidelity on one tested triplet. Use this as proof of mechanism, not as a claim that the historical ibmq_jakarta pulse path is still available.

## Bosonic GKP logical qudit

The 2025 hardware consisted of:
- tantalum transmon ancilla.
- dispersively coupled 3D superconducting microwave cavity.
- cavity stores the logical qudit.

Ideal square GKP qudit:

~~~text
ell_d = sqrt(pi*d)
S_X = D(ell_d)
S_Z = D(i*ell_d)
X_d = D(sqrt(pi/d))
Z_d = D(i*sqrt(pi/d))
Z_d X_d = exp(2*pi*i/d) X_d Z_d
~~~

Finite-energy stabilization uses echoed conditional displacement ECD(beta) plus ancilla rotations. The protocol resets the ancilla between rounds and rotates the cavity phase to alternate the X and Z stabilizers and their inverses.

Reported QEC gains over the best physical cavity qudit in the same system:
- d=3: 1.82 +/- 0.03.
- d=4: 1.87 +/- 0.03.

## Dimension selection

Dimension is an optimization variable rather than a goal.

For every d record:
- level-dependent coherence.
- SPAM confusion matrix.
- spectral crowding.
- off-resonant coupling.
- leakage probability.
- number and duration of control tones.
- single-qudit gate fidelity.
- two-qudit gate fidelity.
- readout latency.
- reset latency.

Select d from measured workload error and runtime. The largest demonstrated dimension is rarely the best engineering point.

## Verification

For native d-level logic verify:
- U-dagger U equals identity in the intended subspace.
- generalized Pauli relation Z_d X_d = omega_d X_d Z_d.
- state-preparation and measurement confusion matrix.
- leakage outside the computational subspace.
- packed virtual-qubit truth tables and phases.
- Schmidt rank for native multiqudit entanglers when relevant.

For transient levels additionally verify the final state returns to the binary subspace.

For bosonic qudits verify stabilizer expectation values, generalized Pauli measurements, QEC gain, oscillator energy, and ancilla-induced error.

## Width-reduction decision rule

Use qudits to reduce carrier count only when all conditions hold:

~~~text
required d-level basis is physically controllable
required local unitary decomposition is available
required inter-carrier entangler is experimentally demonstrated
readout and reset support the dimension
programming interface exposes those controls
post-mapping peak carriers decrease
total pulse and leakage error fit the budget
runtime remains acceptable
~~~

Otherwise use the higher level only as a temporary gate-synthesis resource or use a bosonic qudit for QEC.
