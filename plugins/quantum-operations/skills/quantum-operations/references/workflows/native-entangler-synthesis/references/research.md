# Research basis

1. Quantinuum Helios hardware guide / Native Parameterized Angle Hardware Gates: native RZZ, virtual RZ, angle conventions/floors, Guppy `zz_phase`.
2. Quantinuum H2 guide: RZZ plus optional general SU(4) RXXYYZZ/TK2 target.
3. Quantinuum Quantum Volume report: arbitrary-angle 2Q gates can cut 2Q gate count roughly in half for applicable circuits.
4. Helios Performance Optimization / May 2026 release notes: default runtime 1Q squashing; ~50% Rxy reduction on random mirror and ~25% on phase estimation; runtime behavior is not user-specifiable.

Provider percentages are benchmark observations, not universal factors.
