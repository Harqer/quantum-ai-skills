## Evidence semantics

- **Source-backed** means the algorithm/API has a primary published or maintained reference.
- **Example-backed** means the selected local reference contains concrete implementation steps and executable code (some references compose a short sequence of cells).
- **Verified** means a specified test has actually been executed for that artifact and target library version; citations and syntax checks alone do not establish this.
- **Hardware-backed** means the referenced device-level method was demonstrated on the cited platform; local software examples validate mathematical mappings and data contracts, not hardware performance.

Run `python scripts/check_quantum_evidence.py` for the dependency-free manifest and Python-syntax gate. The checker runs self-contained standard-library examples and parses Python blocks in external-library references. Run the relevant dependency-specific example and record its output before asserting operational readiness.
